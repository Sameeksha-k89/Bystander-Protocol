## 📋 About

**The Bystander Protocol** is a civilian coordination tool designed to help bystanders take effective, safe action during harassment, accidents, or public distress.

Most people who witness these situations **want to help** — but they freeze because they don't know what's socially safe to do alone. This tool gives a room full of strangers a **shared, calm plan in seconds**.

> 🚨 **Not a police app.** No auto-dialing, no reports filed. This is about **civilian first response**.

## 📱 How It Works

### 1️⃣ **Check Safety**
The app first asks: "Is someone in immediate physical danger?" If YES, it directs you to call 112 immediately.

### 2️⃣ **Choose Setting**
Select where this is happening:
- 🚇 Metro / Train
- 🏙️ Street / Sidewalk
- 💼 Workplace
- 🛒 Shop / Queue
- 🎵 Crowded Event
- 🏠 Private Residence

### 3️⃣ **Take Action**
The 5 Ds appear as quick-action buttons:

| Letter | Action | What To Do |
|--------|--------|------------|
| **D** | Distract | Break tension with a neutral interruption |
| **L** | Delegate | Bring in others (staff, security, bystanders) |
| **D** | Document | Record what happened (notes, photos, video) |
| **D** | Delay | Stay with the person afterward — check in |
| **D** | Direct | Use a calm, direct statement (only if safe) |

### 4️⃣ **Submit Report**
Type what happened — **no name required**. All reports are anonymous.

### 5️⃣ **Start Beacon**
Share a 4-character code with people nearby. Everyone who enters the code sees the same plan and can coordinate together.

### 6️⃣ **Download Report**
All witness statements are merged into a **single unified report** — downloadable as a text file.
